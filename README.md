# 🦌 The Mercury Deer

2D экшн-игра на Unity, в которой игрок сражается с врагами, обладающими поведенческим ИИ на основе состояний.

---

## 🎮 Геймплей

- Передвижение игрока по 2D-миру
- Атаки оружием с управлением через мышь
- Враги самостоятельно патрулируют, преследуют и атакуют игрока
- Враги реагируют на получение урона (контратака или восстановление здоровья)

---

## 🏗️ Архитектура

Проект построен на паттерне **MVC**:

| Слой | Классы | Ответственность |
|---|---|---|
| **Model** | `BaseEnemyEntity`, `BaseEnemyAI` | Данные, логика, ИИ |
| **View** | `BaseEnemyView`, `SwordView`, `AmorSwordView` | Анимации, визуал |
| **Weapon** | `Weapon`, `Sword`, `AmorSword` | Логика оружия и урона |

---

## 🤖 Система ИИ врагов

Каждый враг работает через **конечный автомат (FSM)** с тремя состояниями:

```
Roaming → Chasing → Attacking
   ↑__________________________↓
```

| Состояние | Описание |
|---|---|
| `Roaming` | Случайное патрулирование по карте |
| `Chasing` | Преследование игрока при обнаружении |
| `Attacking` | Атака при сближении |

Навигация реализована через **NavMesh2D** (NavMeshPlus).

---

## ⚔️ Враги

### Amor
- ❤️ HP: `50`
- 💥 Урон: `5`
- 🗡️ Оружие: `AmorSword` (атака с прыжком)
- Дальность атаки: `2.5f`

---

## 🗡️ Система оружия

- **Sword** — базовый меч игрока, активируется кликом мыши
- **AmorSword** — меч Amor'а с особой атакующей механикой (прыжок к игроку/падение на игрока)
- **ReactionToTakingHit** — при получении урона враг случайным образом либо наносит ответный урон, либо восстанавливает здоровье
