# 🦌 The Mercury Deer

2D экшн-игра на Unity, в которой игрок сражается с врагами, обладающими поведенческим ИИ на основе состояний.

---

## 🎮 Геймплей

- Передвижение игрока по 2D-миру
- Атаки мечом с прицеливанием через мышь
- Полоска здоровья игрока в HUD
- Враги самостоятельно патрулируют, преследуют и атакуют
- Вспышка белым цветом при получении урона
- Частичные эффекты разрушения объектов на карте
- Всплывающие цифры урона

## 🚀 Быстрый старт

1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/Perepel-coder/TheMercuryDeer.git
   ```
2. Открыть проект в **Unity 2022.3** или новее.
3. Открыть сцену из `Assets/Scenes/`.
4. Нажать **Play** в Unity Editor.

### Управление

| Кнопка | Действие |
|---|---|
| `WASD` / стрелки | Движение |
| ЛКМ | Атака |

| **UI** | `GameMainCanvas` | HUD, полоска здоровья |

## 🤖 Система ИИ врагов

Каждый враг работает через **конечный автомат (FSM)** с пятью состояниями:

```
Idle → Roaming → Chasing → Attacking
                    ↑___________↓
                              Death
```

| Состояние | Описание |
|---|---|
| `Idle` | Стоит без движения |
| `Roaming` | Случайное патрулирование по карте |
| `Chasing` | Преследование игрока при обнаружении |
| `Attacking` | Атака при сближении, с кулдауном |
| `Death` | Логика смерти, отключение объекта |

Навигация реализована через **NavMesh2D** (NavMeshPlus).

## ⚔️ Враги

### Amor
- ❤️ HP: `50`
- 💥 Урон: `5`
- 🗡️ Оружие: `AmorSword` — падающий удар сверху
- 📏 Дальность атаки: `2.5`
- Не меняет направление взгляда во время атаки

### Seraphim
- ❤️ HP: `20`
- 🗡️ Ближний бой, стандартные характеристики
- Активно преследует игрока

---

## 🗡️ Система оружия

| Оружие | Урон | Механика |
|---|---|---|
| `Sword` | `1` | Удар с хит-боксом, управляется мышью |
| `AmorSword` | `10` | Падает сверху на позицию игрока |

- **ActiveWeapon** — компонент, управляющий текущим оружием персонажа и его направлением к курсору.
- **ReactionToTakingHit** — базовая реакция на получение урона (контратака или иное поведение).

---

## ✨ Визуальные эффекты

- **FlashBlink** — белая вспышка на спрайте при попадании (через `MaterialPropertyBlock`).
- **DestructionHandler** — запуск `ParticleSystem` при разрушении объекта.
- **PopUpDamage** — всплывающая цифра урона над целью.
